> **项目名称**：Cure（治愈优选）  
> **产品定位**：「治愈你的日常好物」— 全品类即时零售+会员电商平台  
> **商业模式**：线上下单 + 线下履约（自取/外卖）+ 会员体系，参考瑞幸咖啡模式升级为全品类

## 1. 产品概述

### 1.1 产品愿景

Cure 是一个基于微信小程序的**全品类即时零售+会员电商平台**。核心理念是让用户在一个小程序内完成「随时随地、万物可买」的消费体验。我们借鉴瑞幸咖啡成功的线上线下一体化模式，将品类从咖啡扩展到全品类，打造一个兼具便利性、品质感和社交属性的新零售平台。

### 1.2 核心差异化

| 维度 | 传统电商 | Cure |
|------|---------|------|
| 履约方式 | 快递（2-5天） | 自取（最快15分钟）+ 外卖（最快30分钟）+ 快递 |
| 会员机制 | 积分兑换 | 等级体系 + 积分 + 优惠券 + 专属权益 |
| 品类范围 | 单一品类 | 咖啡茶饮、食品零食、家居日用、数码配件、美妆个护、服饰鞋包、图书文具 |
| 社交属性 | 弱 | 微信生态深度整合：分享裂变、拼单、订阅消息 |
| 下单体验 | 多步繁琐 | 借鉴瑞幸：快速选品 → 规格确认 → 一键下单 → 实时追踪 |

### 1.3 品类规划

| 品类 | 示例商品 | 履约方式 |
|------|---------|---------|
| 咖啡茶饮 ☕ | 美式咖啡、拿铁、果茶、奶茶 | 自取 / 外卖 |
| 食品零食 🍪 | 坚果、饼干、巧克力、方便食品 | 自取 / 外卖 / 快递 |
| 家居日用 🏠 | 纸巾、清洁剂、收纳盒、香薰 | 自取 / 外卖 / 快递 |
| 数码配件 📱 | 充电线、手机壳、耳机、充电宝 | 自取 / 快递 |
| 美妆个护 💄 | 面膜、口红、防晒霜、洗发水 | 快递 |
| 服饰鞋包 👗 | T恤、帆布鞋、帆布包、帽子 | 快递 |
| 图书文具 📚 | 畅销书、笔记本、钢笔、贴纸 | 快递 |

## 2. 用户角色

### 2.1 角色定义

| 角色 | 描述 | 核心需求 |
|------|------|---------|
| **普通用户（消费者）** | 平台主力用户，通过小程序浏览商品并下单 | 快速下单、优惠领取、订单追踪 |
| **会员用户** | 已注册并达到一定等级的消费者 | 积分累积、专属折扣、优先配送 |
| **门店管理员** | 负责门店商品上下架、订单处理 | 订单管理、库存管理、履约操作 |
| **平台运营** | 负责活动策划、数据分析和整体运营 | 活动管理、优惠券配置、数据分析 |
| **系统管理员** | 技术运维、权限管理 | 用户管理、权限配置、系统监控 |

> **本期开发范围**：普通用户 + 会员用户（消费者端完整功能）

### 2.2 消费者用户画像

```
姓名：小李
年龄：26岁
职业：互联网运营
场景：工作日午休想喝杯咖啡，顺手买点零食和日用品
需求：打开 Cure 小程序 → 选咖啡（自取）→ 顺便加购零食和纸巾 → 一键下单 → 下楼取咖啡时一起拿走
痛点：不想在多个 App 之间切换，希望一站式解决
```

## 3. 功能需求

### 3.1 在线点单模块（即时零售）

> 类似瑞幸的点单体验：快速选择、规格配置、极速下单、实时追踪

#### 3.1.1 门店选择
- **FR-001**：用户可搜索/定位附近门店
- **FR-002**：展示门店距离、营业状态、预计取餐时间
- **FR-003**：支持切换门店，切换后购物车提示
- **FR-004**：收藏常用门店

#### 3.1.2 点单商品浏览
- **FR-005**：按品类 Tab 展示可点单商品（仅限支持自取/外卖的品类）
- **FR-006**：商品卡片展示：图片、名称、价格、销量标签、优惠标签
- **FR-007**：支持搜索商品名称
- **FR-008**：商品详情页：大图轮播、规格选择（温度/糖量/尺寸等）、价格计算、加入购物车

#### 3.1.3 购物车与下单
- **FR-009**：购物车按门店分组展示
- **FR-010**：支持修改数量、删除商品、清空购物车
- **FR-011**：自动计算优惠（满减/优惠券/会员折扣）
- **FR-012**：选择履约方式：到店自取 / 外卖配送
- **FR-013**：外卖需填写收货地址，计算配送费
- **FR-014**：提交订单 → 微信支付

#### 3.1.4 订单追踪
- **FR-015**：订单状态实时更新：已下单 → 制作中 → 待取货/配送中 → 已完成
- **FR-016**：自取订单展示取餐码
- **FR-017**：外卖订单展示骑手位置（模拟）
- **FR-018**：订单详情：商品清单、金额明细、时间线
- **FR-019**：支持取消订单（仅在"已下单"状态）

### 3.2 商城模块（传统电商）

> 货架式浏览体验，支持搜索、筛选、收藏，快递配送

#### 3.2.1 首页
- **FR-020**：顶部搜索栏 + 扫码入口
- **FR-021**：Banner 轮播（活动/新品推荐）
- **FR-022**：品类图标导航（金刚区，7个品类入口）
- **FR-023**：限时抢购 / 新品首发 / 热销推荐 楼层
- **FR-024**：瀑布流商品推荐

#### 3.2.2 商品分类
- **FR-025**：左侧一级分类，右侧二级分类 + 商品列表
- **FR-026**：商品排序：综合、销量、价格升/降、最新
- **FR-027**：筛选条件：价格区间、品牌、规格
- **FR-028**：搜索结果页：关键词高亮、筛选排序

#### 3.2.3 商品详情
- **FR-029**：商品图片轮播（支持放大预览）
- **FR-030**：价格展示（原价 + 现价 + 会员价）
- **FR-031**：优惠信息标签（满减/优惠券/限时折扣）
- **FR-032**：规格选择（颜色/尺寸/套餐等 SKU）
- **FR-033**：数量选择器 + 库存提示
- **FR-034**：加入购物车 / 立即购买
- **FR-035**：商品描述（图文详情）
- **FR-036**：商品评价列表 + 评价统计
- **FR-037**：收藏/取消收藏
- **FR-038**：分享给好友（微信转发）

#### 3.2.4 购物车
- **FR-039**：商品列表：图片、名称、规格、单价、数量、小计
- **FR-040**：支持勾选/全选、修改数量、删除
- **FR-041**：合计金额（含优惠前/后对比）
- **FR-042**："去结算"按钮（显示选中数量）

#### 3.2.5 下单与支付
- **FR-043**：确认订单页：收货地址、商品清单、配送方式、优惠券、金额明细
- **FR-044**：支持选择/新增收货地址
- **FR-045**：支持选择优惠券
- **FR-046**：运费计算（满X包邮）
- **FR-047**：提交订单 → 微信支付

#### 3.2.6 收藏夹

- **FR-050**：降价提醒标识

### 3.3 会员体系

#### 3.3.1 会员等级
- **FR-051**：四个等级：普通会员 → 银卡会员 → 金卡会员 → 钻石会员
- **FR-052**：等级基于累计消费金额/成长值
- **FR-053**：等级权益差异：折扣率、免运费门槛、生日礼、专属客服
- **FR-054**：等级进度条展示：当前等级、升级还需消费X元

#### 3.3.2 积分体系
- **FR-055**：消费获积分：每消费1元 = 1积分（不同等级倍率不同）
- **FR-056**：积分明细：获取记录、使用记录、过期提醒
- **FR-057**：积分商城：积分兑换商品/优惠券

#### 3.3.3 优惠券
- **FR-058**：优惠券中心：可领取列表、已领取列表
- **FR-059**：优惠券类型：满减券、折扣券、免运费券、新客专享券
- **FR-060**：优惠券状态：未使用、已使用、已过期
- **FR-061**：下单时自动匹配最优优惠券

#### 3.4.1 个人信息
- **FR-062**：头像、昵称（微信授权获取）
- **FR-063**：会员等级 + 成长值进度
- **FR-064**：积分余额 + 优惠券数量

- **FR-066**：订单搜索（按商品名/订单号）
- **FR-067**：订单操作：付款、取消、确认收货、查看物流、申请退款、再次购买、评价

#### 3.4.3 地址管理
- **FR-069**：收货地址列表（最多20个）
- **FR-070**：新增/编辑/删除地址
- **FR-071**：设置默认地址
- **FR-072**：微信地址导入

#### 3.4.4 账户资产

- **FR-074**：充值（固定金额：50/100/200/500）

## 4. 非功能需求

### 4.1 性能需求

| 指标 | 目标值 | 测量方法 |
|------|--------|---------|
| 小程序启动时间 | < 2s（冷启动）/ < 1s（热启动） | WeChat DevTools 性能面板 |
| 首页加载时间 | < 1.5s | 首屏数据就绪 |
| setData 调用 | 单次 < 64KB，频率 < 20次/s | 代码审查 |
| 主包大小 | < 2MB | 构建后检查 |
| API 响应时间 | P95 < 200ms | 服务端监控 |
| 图片加载 | 启用 WebP + 懒加载 | CDN 配置 |

### 4.2 兼容性需求

- **微信版本**：支持微信 8.0+
- **基础库版本**：最低 2.12.0，推荐 3.0+
- **操作系统**：iOS 14+ / Android 8+
- **屏幕适配**：rpx 自适应 + Safe Area 适配

### 4.3 安全性需求

- **数据传输**：全站 HTTPS，API 请求加密
- **认证**：微信登录 + JWT Token，Token 过期自动刷新
- **支付安全**：微信支付官方 SDK，服务端签名验证
- **隐私合规**：遵循《个人信息保护法》，用户授权后方可获取手机号、位置等敏感信息
- **内容安全**：用户评价内容走微信 msgSecCheck 审核

### 4.4 可用性需求

- **离线提示**：网络断开时友好提示，不白屏
- **错误处理**：API 错误统一处理，展示友好提示
- **加载状态**：骨架屏/加载动画，避免空白等待
- **空状态**：列表为空时引导文案 + 操作按钮

### 4.5 可维护性需求

- **代码规范**：ESLint + Prettier 统一代码风格
- **组件化**：高复用性自定义组件
- **分包加载**：按业务模块拆分 subpackages
- **日志**：关键路径日志上报

## 5. 业务流程

### 5.1 点单下单流程（即时零售）

```
用户进入小程序
    │
    ▼
选择/定位门店
    │
    ▼
浏览点单商品（品类Tab）
    │
    ▼
点击商品 → 选择规格（温度/糖量/尺寸等）
    │
    ▼
加入购物车
    │
    ├── 继续加购 ←──────┐
    │                    │
    ▼                    │
去购物车结算             │
    │                    │
    ▼                    │
选择履约方式             │
├── 到店自取             │
└── 外卖配送 → 选择地址   │
    │                    │
    ▼                    │
选择优惠券               │
    │                    │
    ▼                    │
确认订单 → 微信支付 ─────┘（支付失败可重试）
    │
    ▼
支付成功 → 订单追踪页
    │
    ├── 已下单 → 制作中 → 待取货/配送中 → 已完成
    │                                    │
    └── 取消订单（仅"已下单"状态）        ▼
                                    评价/再次购买
```

### 5.2 商城购物流程（快递配送）

```
用户进入商城首页
    │
    ├── 搜索商品 ─────────────┐
    ├── 浏览分类 ─────────────┤
    ├── 首页推荐 → 商品详情 ──┤
    └── 活动页面 → 商品详情 ──┤
                              │
                              ▼
                         商品详情页
                              │
                              ├── 收藏
                              ├── 分享
                              ├── 加入购物车
                              └── 立即购买
                                    │
                                    ▼
                             确认订单页
                              ├── 选择地址
                              ├── 选择优惠券
                              └── 确认金额
                                    │
                                    ▼
                             微信支付
                                    │
                                    ▼
                             支付成功
                                    │
                                    ▼
                             等待发货 → 已发货 → 确认收货 → 评价
```

### 5.3 会员积分流程

```
用户消费
    │
    ▼
订单完成 → 按消费金额 × 等级倍率获得积分
    │
    ▼
积分到账 → 可用于兑换优惠券 / 积分商城商品
    │
    ▼
累计消费金额 ↑ → 成长值 ↑ → 会员等级 ↑
    │
    ▼
等级提升 → 解锁更高折扣 / 免运费门槛 / 更多权益
```

### 5.4 用户登录授权流程

```
用户打开小程序
    │
    ▼
wx.login() 获取 code
    │
    ▼
发送 code 到后端 → 换取 openid + 生成 JWT
    │
    ▼
JWT 存储在本地 → 后续请求自动携带
    │
    ▼
按需请求用户授权：
├── 用户信息（昵称/头像）→ wx.getUserProfile（或头像昵称填写）
├── 手机号 → button open-type="getPhoneNumber"
├── 位置 → wx.getLocation（需声明用途）
└── 订阅消息 → wx.requestSubscribeMessage
```
